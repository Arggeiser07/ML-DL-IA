# Objetivo

Crear una pipeline simple de un pipeline Data Science.

## Flujo

1. Cargar un CSV.
2. Limpiar o imputar valores nulos con la media u sus distintos métodos.
3. Convertir los datos a un DataFrame de pandas.
4. Seleccionar variables predictoras.
5. Entrenar un modelo de scikit-learn.
6. Mostrar métricas básicas.
7. Generar gráficos con seaborn.
8. Uso de Jupyter Notebook

Resultados esperados:

- Número de filas y columnas.
- Tipos de datos.
- Valores nulos por columna.
- Estadísticas descriptivas.
- Matriz de correlación.
- División train/test.
- Métricas del modelo.
- Importancia de variables (si aplica).
- Gráficos exploratorios.
- Gráfico predicción vs realidad.

## Librerías

- pandas
- numpy
- scikit-learn
- seaborn
- matplotlib

## Restricciones

- Todo el código debe estar en un único archivo.
- El código debe ser claro y educativo.
- Debe ejecutarse desde terminal.
